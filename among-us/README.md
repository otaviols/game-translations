# Among Us Audiogame — translations / traduções

`lang/en_US.json` is the reference (every key, maintained with the game). `lang/pt_BR.json` is the
other built-in language. Everything else here was made by players.

`lang/en_US.json` é a referência (todas as chaves, mantido junto com o jogo). `lang/pt_BR.json` é o
outro idioma embutido. O resto foi feito por jogadores.

## Make a translation / Fazer uma tradução

1. In the game's `lang` folder, copy `en_US.json` to `<code>.json` — e.g. `fr_FR.json`, `es_ES.json`.
   The code is letters, digits and underscore only. / Na pasta `lang` do jogo, copie `en_US.json`
   para `<código>.json`. O código é só letras, dígitos e sublinhado.
2. Translate the values. Set `language.name` to the language's own name and `language.translator`
   to yours. / Traduza os valores. Ponha em `language.name` o nome do idioma no próprio idioma e em
   `language.translator` o seu nome.
3. Open the game: the language is already in **Settings → Language**. Play with it for a while. /
   Abra o jogo: o idioma já aparece em **Configurações → Idioma**. Jogue com ele um pouco.
4. In the match list, choose **Send a translation to the people who make the game** and pick it. /
   Na lista de partidas, escolha **Enviar uma tradução para quem faz o jogo** e selecione o idioma.

That's it. You will get a reply inside the game when it is reviewed, and it ships with the next
version. To update it later, edit your file and send it again. / Pronto. Você recebe uma resposta
dentro do jogo quando ela for revisada, e ela vai na versão seguinte. Para atualizar, edite o
arquivo e envie de novo.

## Keeping up with new versions / Acompanhar as versões novas

Each game version adds keys. Compare your file with the `en_US.json` here (the maintainer can also
send you the list of missing keys as a reply in the game). / Cada versão acrescenta chaves. Compare
o seu arquivo com o `en_US.json` daqui (o mantenedor também pode mandar a lista do que falta como
resposta no jogo).
